### Whisper AutoSubtitle

A simple tool to generate subtitles for videos using OpenAI Whisper. It watches a specified folder for new video files, converts them to audio if necessary, transcribes the audio using Whisper, translates the transcription to a desired language, and saves the subtitles in SRT format next to the original video file.

#### Features
- Watches a specified folder for new video or audio files (mp4, mkv, mp3).
- Converts video files to audio if necessary.
- Transcribes audio using OpenAI Whisper.
- Translates the transcription to a desired language.
- Saves subtitles in SRT format next to the original video file.
#### Usage
1. Clone the repository and navigate to the project folder.
2. Install the required dependencies.
3. Configure the settings in the `app.config` file. - not implemented yet
4. Run the script to start watching the specified folder for new video or audio files.
